# 책나무 장부

대치점, 대치도곡점, 대치구룡초점과 강남서초지사, 광진성동지사의 수입·지출을 한 곳에서 입력하고 한눈에 보는 앱입니다.

- 앱 주소: https://claude.ai/artifact/GqUEtvuWvJ6x7Y3tyXdX59 (소유자만 열 수 있음)
- 이 폴더에는 화면 코드(`ledger.html`)만 있습니다. 입력한 기록(수입, 지출, 강사 정보, 급여, 영수증 사진)은 claude.ai 아티팩트 저장소에 있고 이 저장소에는 올리지 않습니다.

## 화면

| 탭 | 내용 |
|---|---|
| 한눈에 | 전체 수입·지출·순이익·현금 잔액, 학원과 지사 따로 보기, 전체 총정리(카드·대출 포함), 지점별 표, 월별 그래프 |
| 내역 | 기간별 모든 기록, 검색, 수정·삭제 |
| 시간표 | 강사 근무 시간표 (요일별·지점별 보기, 한 달에 여러 개, 시작·마감 시각 설정) |
| 급여계산 | 달력에 근무 시간 입력, 시급제·월급제, 4대보험·3.3%, 결근·지각 차감, 실제 입금액 |
| 강사 | 강사 정보, 여러 지점 소속, 계약서 첨부, 월별 급여 내역 |
| 대출·자금 | 법인·개인 대출 잔액, 법인과 개인 사이 돈 |
| 자료 올리기 | 엑셀·CSV 거래내역 올리기, 영수증 사진 AI 읽기 |
| 설정 | 지점·항목 추가, 4대보험 요율, 엑셀 내보내기 |

## 수정해서 다시 올리는 법

`ledger.html`을 고친 뒤 Claude에게 같은 주소로 다시 게시해 달라고 하면 됩니다. 저장된 기록은 그대로 남습니다.
