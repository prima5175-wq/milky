# 책나무 대치본원 블로그 자동화 — Claude 지침

> 이 파일은 새 세션에서 Claude가 자동 로드하는 최상위 지침입니다.
> 고정 정보의 **공식 소스는 `scripts/config.py`** 이며, 이 문서는 그 사본입니다.
> `config.py`를 수정한 뒤에는 이 문서, `templates/_guide.md`, `drafts/*.md` 까지 동기화하세요. (사용 설명서 §3)

---

## 0. 정체성 한 줄

**책나무 대치본원 (1관·한티역) 윤원장**의 네이버 블로그를 위해, 학부모가 신뢰할 수 있는 약 2,000자 글을 매일 1편 생산한다.

---

## 1. 매 글 고정 요소 (절대 변경 금지)

### 1.1 첫 줄 인사말
```
안녕하세요 :)
책나무 대치본원 윤원장입니다.
```

### 1.2 본문 중간 이미지 슬롯
- 정확히 3장: `[이미지 1]`, `[이미지 2]`, `[이미지 3]`
- 각 슬롯 바로 옆 괄호로 **Genspark용 한글 프롬프트**(장면 + 분위기 + 스타일 + 비율) 함께 표기

### 1.3 푸터 (전체 동일)
- `[학원 사진 자리]` 표시
- 학원 이름·주소·전화·인스타·카카오·운영시간
- 해시태그 세트 (15~20개 권장)
- 정확한 값은 `scripts/config.py`의 `FOOTER_BLOCK` 참조

---

## 2. 글 형식 규격

| 항목 | 값 |
|---|---|
| 분량 | 약 2,000자 (±200자) |
| 이미지 | 정확히 3장, 본문 흐름에 자연스러운 위치 |
| 소제목 | 2~4개, `## ` 마크다운 |
| 인용구 | 핵심 한 줄은 `> ` 인용 — 네이버에서 인용 블록으로 변환됨 |
| 굵은 글씨 | 강조 1~3회, `**` 사용 |
| 표 | 정보성 글에는 1개 권장 |
| 링크 | 외부 링크 지양 (네이버 SEO) |

**금지 사항**: `---` 구분선 본문 내부 사용 금지(푸터 직전만 허용), 프론트매터 금지, 이모지 남용 금지(스타일별 규칙 따를 것).

요청 없으면 `default` 사용.

---

## 4. 작업 흐름 (사용 설명서 §1)

1. `ideas/topic_pool.md`에서 오늘 날짜 주제 확인
2. `drafts/YYYY-MM-DD_<제목>.md` 로 초안 저장
3. 자연어 수정 요청에 응답
4. 발행 완료 보고 받으면 → `drafts/` → `posts/` 이동, `topic_pool.md` 상태 `✅ 발행`로 갱신

### 발행 후 정리 명령 예시
> "2026-05-12 글 발행 완료 — posts로 이동하고 topic_pool 갱신해줘"

이때 Claude는:
- `drafts/2026-05-12_*.md` → `posts/2026-05-12_*.md`
- `ideas/topic_pool.md` 해당 행 상태 → `✅ 발행`

## 5. 파일 구조

```
blog-automation/
├── CLAUDE.md                   # ← 지금 이 파일 (자동 로드)
├── scripts/
│   └── config.py               # 고정 정보 단일 소스
├── templates/
│   └── _guide.md               # 작성 원칙·스타일 가이드
├── ideas/
│   └── topic_pool.md           # 발행 일정 + 주제 풀
├── drafts/                     # 초안 (YYYY-MM-DD_*.md)
├── posts/                      # 발행 완료 글
├── resources/                  # 이미지 (YYYY-MM-DD_키워드_N.jpg)
└── memory/                     # 학원·스타일 메모 (Claude 전용)
```

---

## 6. 새 세션 첫 응답 시 점검 사항

새 세션이 시작되면 다음을 자동으로 확인한다:

- [ ] `scripts/config.py`의 `FOOTER_BLOCK`에 `TODO` 표시가 남아있는지 → 있으면 사용자에게 확인
- [ ] `ideas/topic_pool.md` 의 오늘/이번주 일정
- [ ] `drafts/` 의 미완료 초안 (상태 `⏳ 초안` / `📝 검토`)

---

## 7. 보안·실수 방지

- 학원·학생 실명, 학부모 실명, 주소 상세, 학생 사진 본문 노출 금지
- 경쟁 학원 직접 비방 금지
- 입시 결과·합격률 등 검증 안 된 수치 금지
- 의료·심리 진단 표현(예: "ADHD", "난독증") 단정 금지
