# 작성 원칙 · 스타일 가이드

> 이 문서는 글의 **형식과 톤**을 정의합니다. 학원 정보·푸터 같은 사실 데이터는 `scripts/config.py`가 단일 소스입니다.

---

## 1. 독자 페르소나

대치동·한티 일대 **초등 3~6학년 / 중등 1~2학년 자녀를 둔 어머니**.
- 정보 검색을 많이 하고, 학원 비교에 익숙함
- "우리 아이에게 정말 도움이 되는가"가 핵심 판단 기준
- 과장된 마케팅 톤·공포 마케팅에 피로감

→ 글은 **진단 → 해석 → 실천 팁** 흐름이 가장 잘 먹힘.

## 3. 스타일 3종

### 3.1 `default` — 전문 상담 톤 (기본값)
- 어미: `~합니다 / ~입니다 / ~드립니다`
- 이모티콘: **첫 줄 `:)` 외 사용 금지**
- 1인칭: "원장으로서", "저희 책나무에서는"
- 어휘: 차분, 절제, 단정형 회피("~인 것 같습니다", "~경향이 있습니다")

### 3.2 `myelin` — 친근 + 밝은 에너지
- 어미: 구어체 혼용 (`~해요 / ~거든요 / ~답니다`)
- 이모티콘: 단락당 0~2개 (😊 ✨ 📚 ☕ 등 학습/감성 계열)
- 1인칭: "제가", "저희가"
- 어휘: 따뜻함, 일상 비유 적극 사용

### 3.3 `nomad` — 서정 에세이
- 어미: 구어체 + 끊어 쓰기
- 이모티콘: **사용 금지**
- 1인칭: "나는", "내가" (에세이체)
- 어휘: 감각적 묘사, 계절·시간·공기 등 분위기어 사용
- 학원 홍보 톤 최소화 (마무리 푸터에 자연스럽게 연결)

요청 키워드:
- "기본으로", "상담 톤" → `default`
- "미엘린 스타일" → `myelin`
- "꿈꾸는유목민 스타일" → `nomad`

## 4. 이미지 슬롯 표기법

본문 안에서 **반드시 다음 형식**으로 슬롯을 남깁니다:

```
[이미지 1] (Genspark 프롬프트: 초등학생 아이가 식탁에서 책을 읽는 모습, 따뜻한 저녁 조명, 한국 아파트 거실, 사실적, 세로 3:4)
```

- 프롬프트는 한글
- 공식: **장면 + 분위기 + 스타일 + 비율**
- 사람 얼굴 클로즈업, 상표·로고, 글자 삽입은 프롬프트에서 배제

## 5. 금지 표현

| 분류 | 금지 예시 | 대체 |

| 과장 수식 | "최고의", "유일한" | "저희가 중요하게 보는 것" |
| 외부 링크 | http://… 본문 삽입 | 인스타·전화 (푸터에만) |

## 6. SEO 가이드 (네이버 블로그)

- **제목**: 30자 내외, 핵심 키워드 1~2개를 앞쪽에 배치
- **첫 100자**: 검색 미리보기에 노출 → 키워드와 공감 포인트 함께
- **해시태그**: 푸터 세트로 충분, 본문 #태그 사용 금지
- **굵은 글씨**: 단락당 1회 이내, 핵심 명사구만
- **인용구**: 글당 1회 (마무리 한 줄 권장)
