# 스타일 메모 (Claude 전용)

## 자주 빠지는 함정
- 학부모 공포 마케팅 ("이대로면 늦습니다") → 금지
- 단정형 의학·심리 진단 → 금지
- 본문에 #해시태그 → 금지 (푸터에서만)
- `---` 본문 구분선 → 푸터 직전 1회만
- 외부 링크 → SEO 손해, 푸터 연락처 외 사용 금지

## 좋은 문장 감각
- "오늘 저희 교실에서는 …" — 현장감
- "이 시기 부모님들이 가장 많이 물으시는 질문은 …" — 대표성
- "결국 독서는 …" — 한 줄 요약 인용 후보

## 구조 변형 시 주의
- 이미지 슬롯 3개는 가능하면 위치 유지 (본문1·2·3 끝마다)
- 마무리 인용(`>`)은 글의 톤을 가장 강하게 결정 — 신중히
