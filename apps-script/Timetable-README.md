# 주간 시간표 웹앱 — 구글 시트에 바로 저장하기

시간표 도구를 **웹앱 링크 하나**로 열고, 입력한 일정이 **연결된 구글 시트에
자동 저장**되게 하는 방법입니다. 링크는 폰·태블릿·PC 어디서 열어도 같은
데이터를 보여줍니다.

준비물: 구글 시트 1개 (일정이 저장될 곳. 빈 시트로 새로 만들어도 됩니다.)

## 1. Apps Script 열기

1. 저장용 구글 시트를 하나 엽니다. (없으면 새로 만드세요)
2. 상단 메뉴 **확장 프로그램 → Apps Script** 를 클릭합니다.

## 2. 파일 두 개 붙여넣기

Apps Script 편집기 왼쪽 파일 목록에서:

1. 기본 `Code.gs` 안의 내용을 전부 지우고, 이 저장소의
   **`apps-script/Timetable.gs`** 내용을 그대로 붙여넣습니다.
2. `＋` → **HTML** 을 눌러 새 HTML 파일을 만들고, 이름을 정확히
   **`Timetable`** 로 짓습니다. (확장자 `.html` 은 자동으로 붙습니다)
3. 새로 만든 `Timetable.html` 의 내용을 전부 지우고, 이 저장소의
   **`apps-script/Timetable.html`** 내용을 그대로 붙여넣습니다.
4. 저장(Ctrl+S / Cmd+S).

> 시트에서 만든 스크립트(=시트에 붙어 있는 스크립트)라면 `Timetable.gs`
> 맨 위 `SHEET_ID` 는 `''` 그대로 두면 됩니다. 시트와 따로 만든 독립
> 스크립트라면, 시트 주소에서 `/d/` 와 `/edit` 사이의 긴 값을 복사해
> `SHEET_ID = '여기'` 에 넣으세요.

## 3. 웹앱으로 배포

1. 우측 상단 **배포 → 새 배포** 클릭.
2. 유형(톱니바퀴) → **웹앱** 선택.
3. "실행할 사용자"는 **나**, "액세스 권한이 있는 사용자"는 필요에 맞게:
   - 나만 쓸 거면 **나만**,
   - 다른 선생님도 링크로 쓰게 하려면 **전체 허용**(또는 도메인 내 전체).
4. **배포** → 권한 승인 요청이 뜨면 본인 구글 계정으로 승인합니다.
   (경고 화면이 나오면 "고급 → 안전하지 않은 페이지로 이동" 을 눌러 승인)
5. 나오는 **웹앱 URL** (`https://script.google.com/macros/s/.../exec`) 을
   복사합니다. → 이 주소가 시간표 링크입니다. 북마크해 두세요.

첫 실행 때 데이터 탭 **`_시간표데이터`** 가 시트에 자동으로 생깁니다.
(이 탭은 앱 전용이라 직접 수정하지 마세요.)

## 4. 사용

- 링크를 열면 바로 시간표가 뜹니다.
- 일정을 넣고/고치면 화면 왼쪽 위에 **저장 중… → ✔ 저장됨** 표시가 뜨고,
  구글 시트에 자동 저장됩니다. (저장 버튼 따로 없음)
- 다른 기기에서 같은 링크를 열면 저장된 내용이 그대로 보입니다.
- **이미지 저장**: 눌러 나온 그림을 폰에서는 **길게 눌러 저장** → 카톡 전송,
  PC에서는 자동 다운로드되거나 '다운로드' 버튼을 누르면 됩니다.

## 자주 있는 상황

- **코드를 고친 뒤 반영이 안 돼요** → **배포 → 배포 관리 → 연필(수정) →
  버전: 새 버전 → 배포** 로 다시 배포해야 합니다. URL 은 그대로 유지됩니다.
- **여러 명이 동시에 편집하면?** → 마지막으로 저장한 내용이 남습니다.
  같은 시간표를 여러 명이 동시에 크게 고치는 상황은 피하는 게 좋습니다.
- **데이터가 너무 커지면?** → 5만자 넘는 일정도 여러 셀에 나눠 저장하므로
  일반적인 사용량에서는 문제되지 않습니다.
- **백업** → 앱 안의 **백업·복원** 에서 JSON 을 복사해두면 언제든 되살릴 수
  있습니다. (시트 자체를 사본으로 만들어 두어도 됩니다.)

## 웹앱 없이 그냥 써보기

배포가 번거로우면 `docs/timetable.html` 파일 하나만 브라우저로 열어도
똑같이 동작합니다. 다만 이 경우엔 **메모리 모드**라 새로고침하면 초기화되니,
작업 내용은 **백업·복원**으로 따로 저장해 두세요.
