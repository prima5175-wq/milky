# 원장님 진행상황을 구글시트로 모으기

신규 원장님이 오픈 매뉴얼 앱에서 단계를 체크하면, 지사 구글시트에 자동으로
기록됩니다. 지사장님은 그 시트만 열어보시면 전체 지점 현황이 한눈에 보여요.

출석 체크인과 달리 **지사에 딱 한 번만** 설정하면 됩니다. (지점마다 할 필요 없어요)

---

## 무엇이 기록되나요

| 지점명 | 원장님 | 오픈예정일 | D-Day | 진행률(%) | 완료단계 | 완료한 단계 번호 | 퀴즈1 | 퀴즈2 | 퀴즈3 | 최근 업데이트 |
|---|---|---|---|---|---|---|---|---|---|---|
| 대치캠퍼스 | 윤혜림 원장 | 2026-12-01 | 90 | 15 | 3 / 20 | 1, 2, 3 | 90점 | - | - | 2026-09-03 00:41 |

- 지점 하나당 **한 줄**입니다. 다시 보내면 그 줄이 갱신돼요. 줄이 계속 쌓이지 않습니다.
- 진행률 칸은 50% 이상이면 노란색, 100%면 초록색으로 표시됩니다.
- 원장님이 지점 설정을 하기 전에는 아무것도 전송되지 않습니다.

---

## 1. 구글시트 준비

지사에서 쓸 구글시트를 하나 만듭니다. (이름은 자유. 예: `지점 오픈 진행현황`)

탭은 만들지 않아도 됩니다. `오픈진행현황` 탭이 자동으로 생성돼요.

## 2. Apps Script 붙여넣기

1. 그 구글시트에서 **확장 프로그램 → Apps Script** 를 클릭합니다.
2. `Code.gs` 내용을 전부 지우고, 이 저장소의 **`apps-script/ProgressScript.gs`** 를
   그대로 붙여넣습니다.
3. 맨 위 `PROGRESS_TOKEN = 'CHANGE_ME'` 를 원하는 값으로 바꿉니다.
   (예: `booktree2026gs`) — 이 값은 3단계에서 앱에도 똑같이 넣어야 해요.
4. 저장(Ctrl+S).

## 3. 웹앱으로 배포

1. 우측 상단 **배포 → 새 배포**
2. 유형: **웹앱**
3. 실행할 사용자: **나**
4. 액세스 권한이 있는 사용자: **전체 허용**
   - ⚠️ 이게 있어야 원장님들 휴대폰에서 기록을 보낼 수 있어요.
   - 시트 자체는 공개되지 않습니다. 링크를 아는 사람이 이 스크립트를 통해
     **기록만 추가**할 수 있고, 시트 내용을 읽지는 못합니다.
5. **배포** → 권한 승인
6. 나오는 **웹앱 URL** (`https://script.google.com/macros/s/.../exec`) 을 복사합니다.

## 4. 앱에 연결

`booktree-open-manual-app/src/data/manual.js` 위쪽의 `REPORT_CONFIG` 에 입력합니다.

```javascript
export const REPORT_CONFIG = {
  webAppUrl: 'https://script.google.com/macros/s/AKfy...../exec',   // 3단계에서 복사한 주소
  token: 'booktree2026gs',                                          // 2단계에서 정한 값
};
```

저장하고 `main` 에 푸시하면 2~3분 뒤 자동으로 반영됩니다.

**두 값이 비어 있으면 기능이 꺼진 상태**입니다. 아무것도 전송되지 않고 앱은
지금까지처럼 각자 기기에만 저장하며 그대로 동작해요.

---

## 원장님께는 어떻게 보이나요

지점 설정 화면 맨 위에 안내문이 표시됩니다.

> **지사 공유 안내**
> 입력하신 지점 정보와 오픈 20단계 진행률이 지사에 자동으로 공유돼요.
> 지사장님이 진행 상황을 함께 확인하고 필요한 부분을 도와드리기 위한 것이며,
> 독서록·상담 내용 등 다른 정보는 전송되지 않아요.

몰래 수집하지 않고 먼저 알려드리는 게 맞다고 보아 넣었습니다. 문구를 바꾸시려면
`src/screens/settings.jsx` 의 `share-notice` 부분을 수정하세요.

---

## 참고

- 전송은 체크할 때마다 즉시 가지 않고 **2초 모았다가 한 번** 보냅니다.
  여러 단계를 연달아 체크해도 요청이 한 번만 갑니다.
- 전송이 실패해도(네트워크 끊김, 주소 오타 등) **원장님 화면에는 아무 영향이 없습니다.**
  앱은 그대로 동작하고, 다음에 체크할 때 다시 시도합니다.
- 같은 지점명 + 같은 원장님이면 같은 줄을 갱신합니다. 원장님이 지점명을 바꾸면
  새 줄이 생기니, 지점명은 처음에 정확히 입력하도록 안내해 주세요.
- 원장님이 휴대폰을 바꾸시면 앱의 진행률은 초기화되지만, **시트에 남은 기록은
  그대로 유지**됩니다.
- 토큰은 비밀번호가 아니라 장난 요청을 막는 정도의 장치입니다. 앱에 포함되어
  배포되므로 누군가 마음먹으면 볼 수 있습니다. 민감한 정보를 이 시트에
  기록하지 마세요.
