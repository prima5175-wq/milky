# 토키 (Toki)

사회적 대화에 어려움이 있는 아동을 위한 **화용언어·사회성 연습 및 교육 보조 도구**.
보기 → 연습하기 → 실제로 해보기. 검사자가 쓰던 검사 결과를 누적해 장기 변화를 한눈에 봅니다.

> 이 앱은 연습·교육 보조 도구입니다. 검사 결과의 해석과 판단은 전문가가 합니다.

## 현재 진행 상황 (1~6단계 완료)
- Next.js + TypeScript + Tailwind 골격, 한국어/영어 i18n
- DB 스키마와 역할별 접근 제어(RLS): `supabase/migrations/0001_init.sql`
- 검사 카탈로그·검사 기록 구조 (외부 검사는 점수만 입력, 문항은 저장하지 않음)
- **검사 결과 누적 화면** (`/therapist`, 가상 데이터): 점수 입력, 변화 추이 그래프, 두 시점 비교, 재검 예정 알림, 통합 타임라인
  - 점수 방향(높을수록 좋은지)을 모르는 항목은 "좋아짐/나빠짐"을 판정하지 않고 변화량만 보여준다.
  - HTP 같은 그림 검사는 점수 없이 시행 기록·관찰 메모만 남긴다. 자동 해석·채점 없음.
  - 저장소는 `AssessmentRepository` 인터페이스 뒤에 있어 Supabase 연결 시 `demo.ts` 만 교체하면 된다.
- **시나리오 120개 시드** (`content/scenarios/*.json`, 장소별 12개): 전부 `초안`. 연령·단계·영역 고르게 분포, 갈등 상황 45개
  - 형식 검증: `node scripts/validate-scenarios.mjs` (선택지 4개·좋은 응답 포함·어색한 예 구분·길이·금지 표현 등)
  - 감수 화면 `/admin/scenarios`: 초안 → 전문가 검토 → 승인 (승인 시 검토자 필요, 되돌릴 때 사유 필요)
  - 아동 화면·배정 후보에는 **승인된 것만** 나온다 (DB 정책 + 코드에서 이중으로 차단)
- **아동별 연습 설정** (`/therapist/children/[id]/prescription`): 하루 시간·개수·목표 단계·영역, 연령대에 맞는 승인 시나리오 후보 제안(검사자가 확정)
- **아동 화면** (`/child`): 보기 → 질문 → 연습(고르기·말하기·쓰기, 최대 3번) → 미션, 스티커판, 저자극·읽어주기
- **AI 친구** (`POST /api/practice`): 서버에서만 Claude 를 호출한다. `ANTHROPIC_API_KEY` 가 없거나 AI 가 실패·거절·부적절한 응답을 하면 오프라인 엔진으로 계속한다.
  - 구조화 출력(JSON)으로 받고, 아동에게 보이기 전에 길이·금지 표현을 검사한다.
  - 아동의 말은 항상 `<child_reply>` 안에만 넣어 지시문과 분리한다.
- **안전장치**: 안전 키워드는 AI 호출 **전에** 서버에서 먼저 검사한다. 감지되면 연습을 멈추고 이벤트를 기록해 보호자(`/guardian`)·검사자 화면에 알린다. 오프라인 중 감지된 것은 브라우저에 보관했다가 연결되면 올린다.
- **하루 사용 시간 제한**: 서버가 사용 시간을 기록하고 초과하면 연습 요청을 거절한다 (기본 15분).
- **보호자 화면** (`/guardian`, 데모 PIN `1234`): 실제 생활 미션 확인(→ 스티커 5개, 앱 안 연습은 1개), 주간 요약, 대화 팁, 하루 연습 시간 조정, 동의 관리, 안전 알림
  - 점수는 항상 서버가 정한다. 같은 날 같은 이야기를 반복해도, 브라우저에서 점수를 보내도 늘지 않는다.
  - PIN 은 같은 기기에서 아이가 보호자 기능을 쓰지 못하게 하는 간이 장치다(해시 저장, 5번 틀리면 1분 잠금). 실제 로그인이 아니다.
- **가입·동의** (`/signup`): 법정대리인 확인 + 서비스 동의(필수) + 음성/그림/연구 동의(선택, 기본 꺼짐). 동의를 철회하면 아이 화면이 닫히고, 그림 저장 동의를 철회하면 저장된 그림이 삭제된다. 개인정보처리방침·이용약관은 `/legal/*` 초안(법률 검토 필요).
- **그림 검사(HTP 등)** (`/therapist/children/[id]`): 검사자가 관찰 체크·메모·그림 사진을 기록하고 시점별로 나란히 비교한다. 3개월 주기 알림. **자동 해석·점수화는 하지 않는다.** 그림은 보호자의 별도 동의가 있을 때만 저장한다.
- **연습 설정 저장**: 처방 화면에서 정한 하루 시간·개수·목표 단계가 아이 화면과 사용 시간 제한에 바로 반영된다(변경 이력 기록).
- 감수용 검사 목록: `content/assessment-catalog-review.csv` (교수님 기입용)

## 실행
```bash
cd toki
npm install
cp .env.example .env.local   # 값은 Supabase 연결 후 채움
npm run dev                  # http://localhost:3000
```

## 확인
```bash
npm test                 # 단위 테스트
npm run lint:copy        # UI 문구 금지 표현 검사 ("치료한다", "진단한다")
bash scripts/test-rls.sh # 로컬 Postgres 로 마이그레이션 + 권한 테스트 (Postgres 필요)
```

## AI 설정
```bash
# .env.local
ANTHROPIC_API_KEY=sk-ant-...        # 서버에서만 사용. 브라우저로 전달되지 않는다.
TOKI_AI_MODEL=claude-opus-5-5       # 선택. 기본값. 비용이 부담되면 작은 모델 ID 로 바꿔 품질을 비교해 본다.
```
- 아동 한 명이 시나리오 1개를 하면 AI 호출이 최대 3번이다. 비용은 모델에 따라 크게 다르니 운영 전에 측정할 것.
- 현재 안전 이벤트·사용 시간·진행 기록·동의·HTP 기록은 모두 **서버 메모리**에 저장된다(데모). 재시작하면 사라지므로 운영 전에 DB 로 옮겨야 한다. 로그인·권한(RLS) 연결 전까지 치료사용 API 에는 인증이 없다.

## 원칙
- 외부 상용 검사의 문항·도판은 복제하지 않는다. 점수만 검사자가 입력한다.
- 감수(`approved`) 전 시나리오·검사는 아동에게 노출하지 않는다.
- 음성 원본은 저장하지 않는다. 그림 저장은 보호자 별도 동의가 있을 때만.
